# Sudoku for Odoo 19

A bakery-themed Sudoku game module built for Odoo Website using Python algorithms for generation and the OWL
JavaScript framework for frontend rendering.

## Features

- **Stateless Game State:** Runs in the client session; zero database overhead.
- **Python Generator:** Real-time puzzle creation with uniqueness validation.
- **4 Difficulty Settings:** Easy, Medium, Hard, and Extreme.
- **Helper Tools:** 3 hints per board, board skip, and auto-solve confirmation modal.
